# ChatTranslator — перевод чата Hytale: русский ⇄ английский

Инструкция для человека, который не программирует. Читайте сверху вниз по шагам.

---

## Что делает плагин

Каждый игрок видит чат на своём языке.

- Англичанин пишет `where is the spawn?` — русские игроки видят
  `John: где спавн? (перевод)`, а англичане — исходное сообщение.
- Русский пишет `привет всем` — англичане видят `Ivan: hi everyone (translated)`,
  русские — как написано.
- Автор всегда видит своё сообщение так, как написал.

**Язык игрока** определяется сам при первом входе на сервер — по языку игры
(`ru-RU` — русский, `en-US` — английский). Плагин его запоминает. Если у игрока
игра на английском, но пишет он по-русски, плагин начинает переводить ему на русский.
Игрок в любой момент может выбрать язык сам: **`/tr ru`** или **`/tr en`**.

**Как переводится сообщение** — от простого к сложному, и только последний шаг
обращается к сервису перевода:

1. **Разговорник** — готовые переводы частых фраз чата: «привет», «как дела?»,
   «спасибо», «gg», «го», «где спавн?», «иди сюда», «I'm new», «brb», «idk»
   (больше тысячи вариантов) и ваши собственные фразы из файла `phrases.txt`.
2. **Словарь** — около 120 тысяч русских и английских слов во всех формах:
   сообщение из одного слова («меч», «алмазы», «sword») переводится без сервиса.
   Игровые слова переводятся по-игровому: «лук» — bow, а не onion, «печь» — furnace.
3. **Память переводов** — фраза, которую сервис уже переводил, второй раз туда
   не отправляется.
4. **Сервис перевода** — DeepL (если вписан ключ) или бесплатный MyMemory. Он получает
   только то, что не нашлось выше: смысл целых предложений.

В одном сообщении шаги сочетаются: в «привет, я тут новенький!» приветствие
переводится разговорником, а в сервис уходит только «я тут новенький!».

Если сервис не может перевести (не принял ключ, кончился лимит, не работает в стране,
где стоит сервер), переводит следующий по очереди. Если не справился никто, сообщение
приходит без перевода — чат не ломается и ничего не теряется.

**Сообщения плагина цветные**: заголовок `[Переводчик]` голубой, команды (`/tr en`)
жёлтые, выбранный язык зелёный, пояснения серые, проблемы — оранжевые.

> **Про DeepL и код 451.** Если в консоли написано
> `DeepL отказал с кодом 451: он не обслуживает страну, где стоит сервер` — DeepL
> не работает с серверами из этой страны, и ключ тут ни при чём. Плагин сам
> переключится на MyMemory. Чтобы работал именно DeepL, сервер должен стоять
> в другой стране.

## Что понадобится

1. Сервер Hytale.
2. Необязательно: ключ DeepL API (бесплатный тариф — ключ заканчивается на `:fx`,
   500 000 символов в месяц). Без ключа плагин переводит через MyMemory.
3. Около 20 МБ оперативной памяти сервера под словарь.

## Если у вас стоит версия 1.1.0 или 1.0.0

1. Остановите сервер.
2. В папке `mods` **удалите** старый `ChatTranslator-1.1.0.jar` (или `-1.0.0.jar`) —
   два файла плагина сразу класть нельзя.
3. Положите `ChatTranslator-1.2.0.jar` (шаг 1 ниже).
4. Запустите сервер. Ключ, память переводов и языки игроков сохранятся.
   В `config.json` сами допишутся новые поля `LocalDictionary` и `LocalMaxWords`,
   а рядом появится файл `phrases.txt` для ваших фраз.
5. С версии 1.1.0 команда выбора языка — **`/tr`**, а не `/lang` (почему — в разделе
   «Если что-то не работает»).

## Шаг 1. Скачать плагин

Плагин уже собран, собирать ничего не нужно.

1. Откройте страницу
   <https://github.com/ayaft1445-eng/hytaleplug/releases/tag/chattranslator-latest>
2. Внизу, в разделе **Assets**, нажмите на файл **`ChatTranslator-1.2.0.jar`** —
   он скачается в папку «Загрузки».

## Шаг 2. Положить плагин на сервер

1. Остановите сервер.
2. Откройте папку сервера, в ней папку **`mods`** — туда сервер складывает плагины.
3. Скопируйте туда `ChatTranslator-1.2.0.jar`.
4. Запустите сервер. В консоли появятся строки:

   ```
   [ChatTranslator] Готов: перевод чата ru <-> en, переводчики по порядку: DeepL -> MyMemory. …
   [ChatTranslator] Словарь загружен: 106 750 русских и 15 821 английских слов за 300 мс.
   [ChatTranslator] DeepL: работает, в этом месяце израсходовано 0 из 500 000 символов
   [ChatTranslator] MyMemory: работает (проверка: hello -> привет)
   ```

   Через полминуты — ещё одна:

   ```
   [ChatTranslator] Команда выбора языка для игроков: /chatlang, /tr, /перевод, /язык
   ```

Если строк `[ChatTranslator]` в консоли нет — плагин не загрузился: проверьте,
что jar лежит в папке `mods` и что сервер перезапускался.

---

## Шаг 3. Вписать ключ DeepL (необязательно)

Без ключа всё работает через MyMemory. С ключом первым переводит DeepL — он
переводит лучше, если доступен из страны, где стоит сервер.

1. Откройте файл `config.json` в папке плагина — обычно
   `mods/HytaleModding_chattranslator/config.json`.
   На хостинге — через файловый менеджер панели; на своём компьютере — Блокнотом.
2. Найдите строку `"DeepLApiKey": "",` и вставьте ключ **между кавычками**:

   ```json
   "DeepLApiKey": "ваш-ключ-из-кабинета-DeepL:fx",
   ```

   Кавычки и запятая в конце строки должны остаться.
3. Сохраните файл (кодировка UTF-8 — в Блокноте она выбрана по умолчанию).
4. В консоли сервера напишите `translator reload`, затем `translator status`.

> **Ключ храните только в `config.json` на сервере.** Не вставляйте его в файлы
> репозитория на GitHub: репозиторий открытый, и ключом — вместе с вашим месячным
> лимитом — сможет пользоваться кто угодно. Если ключ всё же попал в чужие руки,
> удалите его в кабинете DeepL (Account → API Keys) и создайте новый.

## Шаг 4. Проверить

**В одиночку:** напишите в игре `/tr test` и любой текст — плагин покажет перевод
только вам и скажет, откуда он взят:

```
[Переводчик] привет всем → hi everyone (разговорник)
[Переводчик] алмазы → diamonds (словарь)
[Переводчик] привет, я тут новенький → hi, I'm new here (разговорник + MyMemory)
[Переводчик] я нашёл деревню за рекой → I found a village across the river (MyMemory)
```

Если повторить последнюю проверку, в скобках будет `(память переводов)`.

**Вдвоём (например, с другом):**

1. Один пишет `/tr ru`, другой — `/tr en`.
2. Первый пишет в чат по-русски, второй — по-английски.
3. Каждый видит сообщения другого на своём языке с пометкой `(перевод)` / `(translated)`.

Своё обычное сообщение в чате автор всегда видит без перевода.

## Команды

Сменить язык можно в любой момент игры, отдельное право для этого не нужно.

| Команда | Что делает |
|---|---|
| `/tr` | показывает, какой язык выбран сейчас, и все варианты |
| `/tr ru` | читать чат по-русски: английские сообщения переводятся на русский |
| `/tr en` | читать чат по-английски: русские сообщения переводятся на английский |
| `/tr off` | выключить перевод: все сообщения как есть |
| `/tr auto` | снова брать язык из языка игры |
| `/tr test текст` | перевести текст, показать только себе и сказать, откуда перевод |

У команды четыре имени, все работают одинаково: **`/tr`**, `/chatlang`, `/перевод`,
`/язык` — русские можно набирать, не переключая раскладку: `/язык англ`,
`/перевод русский`, `/язык выкл`. Понимаются и слова `eng`, `english`, `русский`,
`англ`, `выкл`, `тест`.

Для администратора (в консоли сервера — без косой черты, в игре — оператору):

| Команда | Что делает |
|---|---|
| `translator status` | проверяет каждый переводчик настоящим запросом, показывает, кто переводит сейчас, сколько сообщений переведено без сервиса (разговорником и словарём), сколько взято из памяти и какие имена команды `/tr` доступны игрокам |
| `translator reload` | перечитать `config.json` и `phrases.txt` без перезапуска сервера |

При первом входе на сервер игрок получает подсказку про `/tr` на своём языке.

## Настройки (`config.json`)

| Поле | По умолчанию | Что значит |
|---|---|---|
| `DeepLApiKey` | `""` | ключ DeepL API |
| `Translators` | `["deepl", "mymemory"]` | переводчики по порядку. Только MyMemory: `["mymemory"]` |
| `MyMemoryEmail` | `""` | ваша почта для MyMemory: с ней лимит 50 000 символов в день вместо 5 000 |
| `DefaultLanguage` | `"en"` | язык для игроков, у которых игра не на русском и не на английском: `"ru"` или `"en"` |
| `MarkTranslations` | `true` | дописывать `(перевод)` / `(translated)` после переведённого сообщения |
| `ShowOriginal` | `false` | вместо пометки показывать в скобках исходный текст: `Джон: где спавн? (where is the spawn?)` |
| `LearnLanguageFromChat` | `true` | если игрок с английской игрой пишет по-русски — переводить ему на русский |
| `JoinHint` | `true` | подсказка про `/tr` при первом входе |
| `MemoryMaxPhrases` | `20000` | сколько фраз хранить в памяти переводов |
| `LocalDictionary` | `true` | переводить частые фразы и отдельные слова на сервере, без сервиса. `false` — всё через сервис, как в версии 1.1.0 (`phrases.txt` тогда тоже не действует) |
| `LocalMaxWords` | `1` | сколько слов подряд можно перевести по словарю (подробнее ниже) |

После правки: `translator reload` в консоли или перезапуск сервера.
Если в файле ошибка (забыта кавычка или запятая), плагин напишет в консоли номер
строки, где она, и продолжит работать с прежними настройками.

**Про лимит MyMemory.** Без почты MyMemory переводит 5 000 символов в день — это
примерно 150–250 новых сообщений. Частые фразы и отдельные слова переводятся на
сервере, повторяющиеся — берутся из памяти, и в лимит они не входят. Если сервер
большой, впишите в `MyMemoryEmail` свою почту — лимит станет 50 000 символов в день.
Регистрироваться не нужно: почта просто уходит вместе с запросом.

## Перевод на сервере: разговорник и словарь

### Что переводится без сервиса

- **Фразы из разговорника** — если предложение целиком состоит из фразы:
  «Как дела?», «спасибо большое», «где спавн», «не знаю», «gg wp», «how are you»,
  «brb». Регистр, «ё», знаки препинания и смайлы не мешают: «Привет!!! :)» — тоже фраза.
- **Обращения в начале или в конце предложения через запятую**: «привет, …»,
  «да, …», «ок, …», «ребят, …», «…, спасибо», «…, пожалуйста». Всё остальное
  в предложении уходит в сервис. Если после запятой идёт придаточное
  («спасибо, что помог», «хорошо, что ты пришёл»), предложение целиком уходит
  в сервис, чтобы не потерять смысл.
- **Сообщения из одного слова** — по словарю: «меч» → sword, «Алмазы!» → «Diamonds!»,
  «house» → «дом». Числа, ники, ссылки и слова, уже написанные на языке читателя,
  не мешают и остаются как есть: «5 алмазов» → «5 diamonds».

Все предложения, которые переводит сервис, отправляются одним запросом, чтобы не
терялась связь между ними.

### Что остаётся сервису

Всё, где важен смысл: предложения из нескольких слов, которых нет в разговорнике.
В словарь намеренно не попали слова, которые по одному переводятся неоднозначно:
формы глаголов («иду», «сделал»), совпадающие формы разных слов («стали» — от
«сталь» или «стать»?), английские служебные слова (can, will, the) — их переводит
сервис в контексте.

### Настройка `LocalMaxWords`

Сколько слов подряд переводить по словарю, если фразы нет в разговорнике:

| Значение | Что будет |
|---|---|
| `0` | словарь не используется, без сервиса переводятся только фразы из разговорника |
| `1` (по умолчанию) | по словарю переводятся только сообщения из одного слова — так точнее всего |
| `2`–`5` | короткие сообщения переводятся слово за словом: «дай мне меч» → «give me sword». Сервис вызывается реже, но перевод грубее: без артиклей, порядка слов и склонений |

Если такую фразу сервис уже переводил, берётся его перевод из памяти — он точнее.

### Свои фразы: файл `phrases.txt`

Лежит рядом с `config.json` и создаётся сам с примерами. Ваши строки важнее
встроенного разговорника, словаря и памяти. Одна строка — одна фраза:

```
го на арену = let's go to the arena
где магазин = where is the shop
спавн > spawn
пока < see ya later
```

- `русский = english` — перевод в обе стороны;
- `русский > english` — только с русского на английский;
- `русский < english` — только с английского на русский;
- строки с `#` в начале не действуют.

Фраза сработает, когда предложение целиком из неё состоит; регистр, «ё» и знаки
препинания не важны. Отдельные слова, которые должны переводиться по-вашему и внутри
предложений (при `LocalMaxWords` больше 1), пишите после строки `[слова]`:

```
[слова]
кирка = pickaxe
верстак = workbench
```

Приветствия и подобное, которые можно отделять запятой в начале или в конце
предложения, — после строки `[обращения]`. Слова, которые переводить не нужно
вовсе (понятны всем), — после строки `[как есть]`, по одному в строке.

Сохраните файл в UTF-8 и напишите `translator reload`. Если в какой-то строке
ошибка, `translator reload` и консоль покажут её номер; остальные строки работают.

**Как исправить неудачный перевод** — впишите правильный в `phrases.txt`. Это
быстрее и надёжнее, чем править `memory.json`, и не требует остановки сервера.

## Память переводов (`memory.json`)

Лежит рядом с `config.json`. Здесь хранятся переводы сервиса. Одна строка — одна фраза:

```json
{"from": "ru", "to": "en", "count": 12, "text": "я тут новенький!", "translation": "I'm new here!"},
```

- `from` / `to` — направление перевода;
- `text` — фраза (хранится маленькими буквами без лишних пробелов, поэтому
  «Где спавн», «где  спавн» и «ГДЕ СПАВН» — одна фраза);
- `translation` — перевод;
- `count` — сколько раз фраза встречалась.

**Как это экономит лимит.** В сервис уходит только то, чего нет в `phrases.txt`,
разговорнике, словаре и памяти. Сколько переводов пришло из памяти и сколько
сообщений переведено без сервиса, показывает `translator status`.

**Когда память заполнится** (`MemoryMaxPhrases`), плагин освободит место:
сначала забудет фразы, которые встретились один раз и давно не повторялись.
Повторяющиеся фразы остаются.

Править `memory.json` можно только при остановленном сервере (иначе плагин
перезапишет файл при сохранении). Чтобы плагин забыл фразу, удалите её строку целиком.
Память сохраняется каждые 5 минут и при остановке сервера.

---

## Языки игроков (`players.json`)

Тоже рядом с `config.json`. Для каждого игрока: имя, язык (`lang`), включён ли
перевод (`translate`) и откуда взялся язык (`source`: `game` — из языка игры,
`chat` — понят по сообщениям, `command` — выбран через `/tr`). Руками править не
нужно — игроки сами меняют язык командой `/tr`.

## Обновление плагина

1. Скачайте новый jar со страницы Releases (шаг 1).
2. Остановите сервер, **удалите старый** `ChatTranslator-….jar`, положите новый.
3. Запустите сервер.

Папка с `config.json`, `phrases.txt`, `memory.json` и `players.json` остаётся:
ключ, ваши фразы, память и языки игроков не пропадут.

## Как поменять сам плагин

Исходный код лежит в ветке `claude/beautiful-cray-e4znih` репозитория
<https://github.com/ayaft1445-eng/hytaleplug>.

| Что поменять | Файл | Что искать |
|---|---|---|
| Тексты подсказок, `(перевод)` / `(translated)` | `src/main/java/dev/hytalemodding/chattranslator/core/Texts.java` | текст в кавычках |
| Цвета сообщений плагина и пометки `(перевод)` | `src/main/java/dev/hytalemodding/chattranslator/Render.java` | `"#4fc3f7"` и другие коды цветов |
| Встроенный разговорник | `src/main/resources/dictionary/phrases.txt` | тот же формат, что у `phrases.txt` сервера |
| Словарь | `src/main/resources/dictionary/*.tsv` | собирается скриптом `tools/build_dictionary.py` (как — написано в начале скрипта); игровые значения слов — `GLOSSARY_RU` и `GLOSSARY_EN` в нём же |
| Имена команды `/tr` | `src/main/java/dev/hytalemodding/chattranslator/commands/TranslateCommand.java` | `NAME` и `ALIASES` |
| Как часто сохраняются файлы | `src/main/java/dev/hytalemodding/chattranslator/core/TranslatorCore.java` | `scheduleWithFixedDelay` |
| Версия плагина | `gradle.properties` и `src/main/resources/manifest.json` | `version = 1.2.0` и `"Version"` |

Цвет пишется как в HTML: `#` и шесть знаков, например `#ff0000` — красный.
Для своих фраз менять плагин не нужно — для этого есть `phrases.txt` на сервере.

Не называйте команды `lang`, `i18n`, `translation` или `internationalization` —
эти имена заняты встроенной командой сервера.

После правки:

1. Сохраните изменения в ветку `claude/beautiful-cray-e4znih` на GitHub
   (кнопка карандаша на странице файла → **Commit changes**).
2. Откройте вкладку **Actions** и дождитесь зелёной галочки. Сборка заодно
   прогоняет автоматические проверки — если что-то сломано, галочка будет красной,
   и старый jar на странице Releases останется.
3. Свежий jar появится на странице Releases (шаг 1). Поставьте его как при обновлении.

Большинство настроек меняется без правки кода — через `config.json` и `phrases.txt`.

## Если что-то не работает

| Что в консоли / в игре | Что делать |
|---|---|
| `/lang en` отвечает «Could not find subcommand» и предлагает `/lang gen` | `/lang` — встроенная команда сервера для языковых файлов Hytale, к плагину она не относится. Пишите `/tr en` |
| Нет строк `[ChatTranslator]` | Плагин не загрузился: jar не в папке `mods` или сервер не перезапускался |
| `Заняты другой командой сервера или плагина: /tr` | Другой плагин забрал это имя — пользуйтесь оставшимися (`/chatlang`, `/перевод`, `/язык`) |
| `DeepL отказал с кодом 451` | DeepL не работает в стране, где стоит сервер. Переводит MyMemory, делать ничего не нужно |
| `DeepL не принял ключ (код 403)` | Ключ вписан с ошибкой: скопируйте его заново из кабинета DeepL, `translator reload` |
| `исчерпан месячный лимит символов DeepL (код 456)` | До следующего месяца переводит MyMemory |
| `исчерпан дневной лимит MyMemory` | Впишите почту в `MyMemoryEmail` (лимит станет 50 000 в день) или подождите до завтра. Фразы из разговорника и словаря переводятся и без лимита |
| `MyMemory: не работает — не удалось подключиться` | У сервера нет доступа в интернет к `api.mymemory.translated.net` — спросите хостинг |
| `Сейчас все переводчики на паузе` | Ни один сервис недоступен: без перевода идут сообщения, которых нет в разговорнике, словаре и памяти. Причины — в строках выше |
| `Словарь не загружен (java.lang.OutOfMemoryError …)` | Серверу не хватило памяти на словарь (около 20 МБ). Остальное работает; дайте серверу больше памяти или поставьте `LocalDictionary: false` |
| `phrases.txt, строка N: …` | В этой строке `phrases.txt` ошибка (например, нет знака `=`): исправьте и `translator reload` |
| `phrases.txt, файл не в UTF-8` | Файл сохранён в старой кодировке. Он прочитан, но лучше пересохраните его в UTF-8 |
| `В файле … config.json ошибка: строка N …` | В этой строке пропущена кавычка или запятая: исправьте и `translator reload` |
| Слово переводится не так, как принято на сервере | Впишите свой перевод в `phrases.txt`, `translator reload` |
| Игроку переводит не на тот язык | Пусть напишет `/tr ru` или `/tr en` |
| Двум русским игрокам ничего не переводится | Так и задумано: переводится только тем, кто читает на другом языке |

## Ограничения

- Переводится обычный чат. Личные сообщения (`/msg`) и сообщения других плагинов
  не переводятся.
- Языки — русский и английский. Сообщение с кириллицей считается русским,
  с латиницей — английским.
- Разговорник и словарь переводят мгновенно. Сервису на новую фразу нужно
  примерно 0,2–1 секунды, поэтому у получателя перевода она появляется чуть позже,
  чем у остальных. Порядок сообщений при этом сохраняется.
- Словарь переводит слово одним значением — самым частым или игровым. Если на вашем
  сервере слово значит другое, впишите его в `phrases.txt`.
- MyMemory переводит проще DeepL и не берёт тексты длиннее 500 байт
  (примерно 250 русских букв) — такие уходят без перевода.

## Откуда словарь

Словарь собран из данных проекта [OpenRussian.org](https://en.openrussian.org)
(выгрузка <https://github.com/Badestrand/russian-dictionary>), лицензия
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Для плагина из него
отобраны частые слова (по частотам [wordfreq](https://github.com/rspeer/wordfreq)),
оставлено по одному переводу, убраны ударения и неоднозначные формы, для игровых
слов выбрано игровое значение. Файлы словаря в плагине (`dictionary/ru-en.tsv`,
`dictionary/en-ru.tsv`) распространяются на тех же условиях CC BY-SA 4.0.
