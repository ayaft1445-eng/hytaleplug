# Меню сервера (плагин SimpleMenu) — установка с нуля

Инструкция написана так, чтобы её мог выполнить человек, который не программирует.
Читать сверху вниз, ничего не пропуская.

---

## Что делает этот плагин

1. У каждого игрока, который зашёл на сервер, **в правом нижнем углу экрана** появляется
   постоянная плашка с надписью `МЕНЮ — /menu`.
2. Команда **`/menu`** в чате открывает окно меню.
3. В окне — **две вкладки**: «МИНИ-ИГРЫ» и «ТАБЛИЦА ЛИДЕРОВ». Они переключаются кнопками,
   в обеих написано «Добро пожаловать».
4. Закрыть окно можно кнопкой «ЗАКРЫТЬ» или клавишей ESC.

### Про клавишу J — важно прочитать

Открывать меню по клавише **J сервер не может**. Это не лень и не ошибка: серверные
плагины Hytale вообще не получают нажатия клавиш от клиента. Сервер видит только:
движение, нажатия мыши (и то не во всех режимах камеры), смену слота в хотбаре,
сообщения в чат и команды. Отдельного события «игрок нажал клавишу» в серверном
API нет — это подтверждается всей доступной документацией по серверу.

Поэтому меню открывается командой `/menu`, а плашка в углу служит подсказкой.
Как только (и если) в игре появится клиентский API для своих клавиш — меню можно
будет повесить на J, менять придётся только одно место в коде.

## Шаг 1. Скачать готовый файл плагина

Плагин уже собран — собирать ничего не нужно.

1. Открой страницу: <https://github.com/ayaft1445-eng/hytaleplug/releases/latest>
2. Внизу, в разделе **Assets**, нажми на файл **`SimpleMenu-1.1.0.jar`** — он скачается
   в твою папку «Загрузки».

Всё, файл плагина у тебя. Переходи к шагу 2.

### Если захочешь собрать плагин сам (необязательно)

**Через GitHub:** залей изменённые файлы в репозиторий → вкладка **Actions** → дождись
зелёной галочки → в разделе **Artifacts** будет свежий jar. Он же автоматически
обновится на странице Releases.

**На своём компьютере:** поставь [JDK 25](https://adoptium.net/temurin/releases/?version=25),
распакуй проект, открой папку в командной строке и выполни `gradlew.bat build`
(на Linux/macOS — `./gradlew build`). Готовый файл появится в `build\libs\`.

---

## Шаг 2. Положить плагин на сервер

1. Остановите сервер Hytale.
2. Найдите папку сервера. В ней должна быть папка **`plugins`**
   (если её нет — создайте папку с именем `plugins`).
3. Скопируйте туда файл `SimpleMenu-1.1.0.jar`.
4. Запустите сервер.

Должно получиться так:

```
папка-сервера/
├── plugins/
│   └── SimpleMenu-1.1.0.jar   ← сюда
├── ...
```

---

## Шаг 3. Проверить, что плагин загрузился

Смотрите в консоль сервера (или в файл логов) сразу после запуска. Там должна быть строка:

```
[SimpleMenu] Плагин загружен. Команда для открытия меню: /menu
```

**Строка есть** — плагин работает, переходите к шагу 4.
**Строки нет** — смотрите раздел «Если что-то не работает».

---

## Шаг 4. Проверить в игре

1. Зайдите на свой сервер.
2. **Проверка плашки:** в правом нижнем углу экрана должна появиться тёмная плашка
   с надписью `МЕНЮ — /menu`. Она появляется сразу после входа в мир.
3. **Проверка меню:** напишите в чат `/menu` и нажмите Enter.
   Должно открыться окно «ГЛАВНОЕ МЕНЮ».
4. **Проверка вкладок:** нажмите кнопку «ТАБЛИЦА ЛИДЕРОВ» — содержимое должно
   переключиться (надпись «Добро пожаловать» перерисуется). Нажмите «МИНИ-ИГРЫ» —
   вернётесь на первую вкладку.
5. **Проверка закрытия:** нажмите «ЗАКРЫТЬ» или клавишу ESC — окно должно закрыться.

Если все пять пунктов прошли — плагин работает как задумано.

## Если что-то не работает

| Что видно | Почему так | Что делать |
|---|---|---|
| В логе нет строки `[SimpleMenu]` | Файл не в той папке, или сервер не той версии | Проверьте, что jar лежит в `plugins/`. Плагин рассчитан на сервер версии 0.5.3–0.5.x |
| В логе ошибка со словом `Main` или `ClassNotFound` | Повреждённый или не тот jar | Скачайте/соберите jar заново |
| Команда `/menu` пишет «команда не найдена» | Плагин не загрузился | Вернитесь к шагу 3 |
| При вводе `/menu` выкидывает с сервера | Ошибка в файле разметки `.ui` | Пришлите мне текст ошибки из лога сервера — поправлю разметку |
| Меню открылось, но кнопки не реагируют | Не совпали имена кнопок в коде и разметке | Пришлите лог, там будет строка про `event bindings` |
| Плашки в углу нет, а меню работает | Плашка вешается при входе в мир | Выйдите и зайдите на сервер заново |
| Вместо русских букв — квадратики | В шрифте клиента нет кириллицы | Замените русский текст на латиницу (см. ниже, где менять) |

Во всех случаях, когда просят «прислать лог» — нужен кусок текста из консоли сервера
сразу после ошибки, примерно 20–30 строк.

## Что можно поменять самому (без программирования)

Все файлы открываются обычным «Блокнотом», лучше — «Блокнотом++» или VS Code.
Папка с внешним видом: `src/main/resources/Common/UI/Custom/SimpleMenu/`

| Что поменять | Файл | Что искать внутри |
|---|---|---|
| Размер окна меню | `MainMenu.ui` | `Anchor: (Width: 960, Height: 600);` в самом верху |
| Заголовок окна | `MainMenu.ui` | `Text: "ГЛАВНОЕ МЕНЮ";` |
| Цвет фона окна | `MainMenu.ui` | `Background: #1a0f2e(0.98);` |
| Цвет выбранной вкладки | `TabActive.ui` | `Background: #7c3aed` (и `#8b5cf6` — при наведении) |
| Цвет невыбранной вкладки | `TabIdle.ui` | `Background: #2d1b4e` |
| Текст внутри вкладки «Мини-игры» | `Panel_Minigames.ui` | `Text: "Добро пожаловать";` |
| Текст внутри «Таблицы лидеров» | `Panel_Leaderboard.ui` | `Text: "Добро пожаловать";` |
| Текст внутри «Косметики» | `Panel_Cosmetics.ui` | `Text: "В процессе создания";` |
| Текст внутри «Миров» | `Panel_Worlds.ui` | `Text: "Скоро будет доступно";` |
| Текст плашки в углу | `MenuHud.ui` | `Text: "МЕНЮ — /menu";` |
| Положение плашки | `MenuHud.ui` | `Right: 24, Bottom: 24` — отступы от края в пикселях |
| Названия вкладок | `src/main/java/dev/hytalemodding/simplemenu/ui/MainMenuPage.java` | список `TAB_TITLES` |
| Название команды | `src/main/java/dev/hytalemodding/simplemenu/commands/MenuCommand.java` | строка `super("menu", ...)` |

Ширина одной вкладки — `Anchor: (Width: 228, ...)` в `TabActive.ui` и `TabIdle.ui`.
Если добавляешь пятую вкладку, уменьши ширину так, чтобы сумма влезла в окно
(ширина окна минус 48 на отступы).

После любой правки нужно **заново собрать jar** (шаг 1) и **заменить файл на сервере** (шаг 2).

## Из чего состоит проект

```
src/main/java/dev/hytalemodding/simplemenu/
├── SimpleMenuPlugin.java          главный файл: включает команду и плашку
├── commands/MenuCommand.java      команда /menu
└── ui/
    ├── MainMenuPage.java          логика меню: какая вкладка выбрана
    └── MenuHud.java               плашка в углу экрана

src/main/resources/
├── manifest.json                  описание плагина для сервера
└── Common/UI/Custom/SimpleMenu/
    ├── MainMenu.ui                рамка меню: заголовок, полоса вкладок, содержимое
    ├── TabActive.ui               кнопка выбранной вкладки (яркая)
    ├── TabIdle.ui                 кнопка невыбранной вкладки (тёмная)
    ├── Panel_Minigames.ui         содержимое вкладки «Мини-игры»
    ├── Panel_Leaderboard.ui       содержимое вкладки «Таблица лидеров»
    ├── Panel_Cosmetics.ui         содержимое вкладки «Косметика»
    ├── Panel_Worlds.ui            содержимое вкладки «Миры»
    └── MenuHud.ui                 плашка в углу экрана
```

Как это работает по шагам:

1. Сервер запускается → загружает `SimpleMenuPlugin` → регистрирует команду `/menu`
   и подписывается на событие «игрок зашёл».
2. Игрок зашёл → сервер отправляет ему плашку `MenuHud` (она видна поверх игры).
3. Игрок пишет `/menu` → сервер открывает страницу меню: вставляет рамку,
   затем четыре кнопки вкладок (выбранная — яркая) и содержимое выбранной вкладки.
4. Игрок нажал другую вкладку → клиент сообщает серверу → сервер открывает
   ту же страницу заново, но уже с другой выбранной вкладкой. Поэтому и содержимое,
   и цвет кнопок всегда совпадают с тем, что выбрано.
