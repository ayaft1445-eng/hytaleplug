# ChatTranslator — перевод чата Hytale: русский ⇄ английский

Инструкция для человека, который не программирует. Читайте сверху вниз по шагам.

---

## Что делает плагин

Каждый игрок видит чат на своём языке.

- Англичанин пишет `where is the spawn?` — русские игроки видят
  `John: где спавн? (перевод)`, а англичане — исходное сообщение.
- Русский пишет `привет всем` — англичане видят `Ivan: hi everyone (translated)`,
  русские — как написано.
- Автор всегда видит своё сообщение так, как написал.

**Язык игрока** определяется сам при первом входе на сервер — по языку игры
(`ru-RU` — русский, `en-US` — английский). Плагин его запоминает. Если у игрока
игра на английском, но пишет он по-русски, плагин понимает, что ему удобнее
русский, и начинает переводить ему на русский. Игрок может выбрать язык и сам:
`/lang ru` или `/lang en`.

**Память повторяющихся фраз.** Каждый перевод запоминается. Если фраза
встречается снова («привет всем», «где спавн», «gg»), перевод берётся из памяти:
DeepL не вызывается, лимит символов не тратится, сообщение приходит мгновенно.
Память сохраняется в файл и остаётся после перезапуска сервера.

Если DeepL недоступен (нет интернета, закончился лимит, неверный ключ), сообщения
приходят без перевода — чат не ломается и ничего не теряется.

## Что понадобится

1. Сервер Hytale — тот же, на котором уже работает ваш HubMenu.
2. Ключ DeepL API. Ключ бесплатного тарифа заканчивается на `:fx`
   и даёт 500 000 символов в месяц.

---

## Шаг 1. Скачать плагин

Плагин уже собран, собирать ничего не нужно.

1. Откройте страницу
   <https://github.com/ayaft1445-eng/hytaleplug/releases/tag/chattranslator-latest>
2. Внизу, в разделе **Assets**, нажмите на файл **`ChatTranslator-1.0.0.jar`** —
   он скачается в папку «Загрузки».

---

## Шаг 2. Положить плагин на сервер

1. Остановите сервер.
2. Откройте папку сервера и найдите папку, где уже лежит `HubMenu-….jar`.
   Обычно это папка **`mods`** (на некоторых хостингах она называется `plugins`).
3. Скопируйте туда `ChatTranslator-1.0.0.jar`.
4. Запустите сервер.
5. В консоли сервера появится строка вида:

   ```
   [ChatTranslator] Ключ DeepL не задан, поэтому чат пока не переводится. Откройте файл
   /…/mods/HytaleModding_chattranslator/config.json, впишите ключ в поле DeepLApiKey …
   ```

   Это нормально: плагин установился и создал файл настроек. В строке написан
   полный путь к этому файлу — он понадобится на следующем шаге.

Если строки `[ChatTranslator]` в консоли нет — плагин не загрузился: проверьте,
что jar лежит в той же папке, что и HubMenu, и что сервер перезапускался.

---

## Шаг 3. Вписать ключ DeepL

1. Откройте файл `config.json` по пути из консоли. Обычно это
   `mods/HytaleModding_chattranslator/config.json`.
   На хостинге — через файловый менеджер панели; на своём компьютере — Блокнотом.
2. Найдите строку

   ```json
   "DeepLApiKey": "",
   ```

3. Вставьте ключ **между кавычками**:

   ```json
   "DeepLApiKey": "ваш-ключ-из-кабинета-DeepL:fx",
   ```

   Кавычки и запятая в конце строки должны остаться.
4. Сохраните файл (кодировка UTF-8 — в Блокноте она выбрана по умолчанию).
5. В консоли сервера напишите `translator reload` (или просто перезапустите сервер).
6. Проверьте ключ: напишите в консоли `translator status`. Должна появиться строка:

   ```
   DeepL: ключ работает, в этом месяце израсходовано 0 из 500 000 символов
   ```

> **Ключ храните только в `config.json` на сервере.** Не вставляйте его в файлы
> репозитория на GitHub: репозиторий открытый, и ключом — вместе с вашим месячным
> лимитом — сможет пользоваться кто угодно. Если ключ всё же попал в чужие руки,
> удалите его в кабинете DeepL (Account → API Keys) и создайте новый.

---

## Шаг 4. Проверить в игре

Нужны два игрока (например, вы и друг):

1. Один пишет `/lang ru`, другой — `/lang en`.
2. Первый пишет в чат по-русски, второй — по-английски.
3. Каждый должен видеть сообщения другого на своём языке с пометкой
   `(перевод)` / `(translated)`.

Своё сообщение автор видит без перевода, поэтому в одиночку перевод не проверить.

---

## Команды

| Команда | Кто может | Что делает |
|---|---|---|
| `/lang ru` | любой игрок | читать чат по-русски: английские сообщения переводятся на русский |
| `/lang en` | любой игрок | читать чат по-английски: русские сообщения переводятся на английский |
| `/lang auto` | любой игрок | снова брать язык из языка игры |
| `/lang off` | любой игрок | выключить перевод: все сообщения как есть |
| `translator status` | консоль сервера или оператор (`/translator status`) | работает ли ключ, сколько символов DeepL израсходовано за месяц, сколько переводов взято из памяти |
| `translator reload` | консоль сервера или оператор | перечитать `config.json` без перезапуска сервера |

`/lang` понимает и русские слова: `/lang русский`, `/lang англ`, `/lang выкл`.

При первом входе на сервер игрок получает подсказку про `/lang` на своём языке.

## Настройки (`config.json`)

| Поле | По умолчанию | Что значит |
|---|---|---|
| `DeepLApiKey` | `""` | ключ DeepL API |
| `DefaultLanguage` | `"en"` | язык для игроков, у которых игра не на русском и не на английском: `"ru"` или `"en"` |
| `MarkTranslations` | `true` | дописывать `(перевод)` / `(translated)` после переведённого сообщения |
| `ShowOriginal` | `false` | вместо пометки показывать в скобках исходный текст: `Джон: где спавн? (where is the spawn?)` |
| `LearnLanguageFromChat` | `true` | если игрок с английской игрой пишет по-русски — переводить ему на русский |
| `JoinHint` | `true` | подсказка про `/lang` при первом входе |
| `MemoryMaxPhrases` | `20000` | сколько фраз хранить в памяти переводов |

После правки: `translator reload` в консоли или перезапуск сервера.
Если в файле ошибка (забыта кавычка или запятая), плагин напишет в консоли номер
строки, где она, и продолжит работать с прежними настройками.

## Память переводов (`memory.json`)

Лежит рядом с `config.json`. Одна строка — одна фраза:

```json
{"from": "ru", "to": "en", "count": 12, "text": "где спавн", "translation": "where is the spawn"},
```

- `from` / `to` — направление перевода;
- `text` — фраза (хранится маленькими буквами без лишних пробелов, поэтому
  «Где спавн», «где  спавн» и «ГДЕ СПАВН» — одна фраза);
- `translation` — перевод;
- `count` — сколько раз фраза встречалась.

**Как это экономит лимит.** В DeepL уходит только фраза, которой ещё нет в памяти.
Всё повторное берётся отсюда. Сколько переводов пришло из памяти, а сколько из
DeepL, показывает `translator status`.

**Когда память заполнится** (`MemoryMaxPhrases`), плагин освободит место:
сначала забудет фразы, которые встретились один раз и давно не повторялись.
Повторяющиеся фразы остаются.

**Как исправить неудачный перевод** (например, сленг):

1. Остановите сервер (иначе плагин перезапишет файл при сохранении).
2. Найдите строку с фразой и исправьте `translation`.
3. Сохраните файл в UTF-8 и запустите сервер.

Чтобы плагин забыл фразу, удалите её строку целиком. Можно и добавить свою строку
в том же виде — плагин будет использовать её вместо DeepL.

Память сохраняется каждые 5 минут и при остановке сервера.

---

## Языки игроков (`players.json`)

Тоже рядом с `config.json`. Для каждого игрока: имя, язык (`lang`), включён ли
перевод (`translate`) и откуда взялся язык (`source`: `game` — из языка игры,
`chat` — понят по сообщениям, `command` — выбран через `/lang`). Руками править не
нужно — игроки сами меняют язык командой `/lang`.

---

## Обновление плагина

1. Скачайте новый jar со страницы Releases (шаг 1).
2. Остановите сервер, удалите старый `ChatTranslator-….jar`, положите новый.
3. Запустите сервер.

Папка с `config.json`, `memory.json` и `players.json` остаётся: ключ, память
и языки игроков не пропадут.

## Как поменять сам плагин

Исходный код лежит в ветке `claude/beautiful-cray-e4znih` репозитория
<https://github.com/ayaft1445-eng/hytaleplug>.

| Что поменять | Файл | Что искать |
|---|---|---|
| Тексты подсказок, `(перевод)` / `(translated)` | `src/main/java/dev/hytalemodding/chattranslator/core/Texts.java` | текст в кавычках |
| Цвет пометки `(перевод)` | `src/main/java/dev/hytalemodding/chattranslator/ChatListener.java` | `NOTE_COLOR = "#9a9a9a"` |
| Название команды `/lang` | `src/main/java/dev/hytalemodding/chattranslator/commands/LangCommand.java` | `super("lang", …)` |
| Как часто сохраняются файлы | `src/main/java/dev/hytalemodding/chattranslator/core/TranslatorCore.java` | `scheduleWithFixedDelay` |
| Версия плагина | `gradle.properties` и `src/main/resources/manifest.json` | `version = 1.0.0` и `"Version"` |

После правки:

1. Сохраните изменения в ветку `claude/beautiful-cray-e4znih` на GitHub
   (кнопка карандаша на странице файла → **Commit changes**).
2. Откройте вкладку **Actions** и дождитесь зелёной галочки. Сборка заодно
   прогоняет автоматические проверки — если что-то сломано, галочка будет красной,
   и старый jar на странице Releases останется.
3. Свежий jar появится на странице Releases (шаг 1). Поставьте его как при обновлении.

Большинство настроек меняется без правки кода — через `config.json`.

## Если что-то не работает

| Что в консоли / в игре | Что делать |
|---|---|
| Нет строк `[ChatTranslator]` | Плагин не загрузился: jar не в той папке или сервер не перезапускался |
| `Ключ DeepL не задан` | Шаг 3 |
| `DeepL не принял ключ (код 403)` | Ключ вписан с ошибкой: скопируйте его заново из кабинета DeepL, `translator reload` |
| `исчерпан месячный лимит символов DeepL (код 456)` | Лимит закончился до следующего месяца. Фразы из памяти продолжают переводиться, остальные идут без перевода |
| `не удалось подключиться к DeepL` | У сервера нет доступа в интернет к `api-free.deepl.com` — спросите хостинг |
| `В файле … config.json ошибка: строка N …` | В этой строке пропущена кавычка или запятая: исправьте и `translator reload` |
| Игроку переводит не на тот язык | Пусть напишет `/lang ru` или `/lang en` |
| Двум русским игрокам ничего не переводится | Так и задумано: переводится только тем, кто читает на другом языке |

## Ограничения

- Переводится обычный чат. Личные сообщения (`/msg`) и сообщения других плагинов
  не переводятся.
- Языки — русский и английский. Сообщение с кириллицей считается русским,
  с латиницей — английским.
- Новая фраза переводится примерно за 0,2–0,5 секунды, поэтому у получателя
  перевода она появляется чуть позже, чем у остальных. Фразы из памяти приходят
  сразу. Порядок сообщений при этом сохраняется.
